## Topics Covered

### SQL
- Basic querying, filtering, sorting, and pagination
- All JOIN types — INNER, LEFT, RIGHT, FULL OUTER, CROSS, SELF
- String, date, and conversion functions
- Aggregate functions with GROUP BY and HAVING
- Subqueries — nested, correlated, EXISTS, ANY, ALL
- Stored procedures with IN, OUT, INOUT parameters
- Triggers — BEFORE/AFTER INSERT, UPDATE, DELETE
- Transactions — COMMIT, ROLLBACK, SAVEPOINT, isolation levels
- Window functions — RANK, DENSE_RANK, LAG, LEAD, running totals
- Views and indexes — creation, optimization, management

### MongoDB
- CRUD operations and document modeling
- Query operators — comparison, logical, array, regex
- Indexing strategies and query performance analysis
- Aggregation pipeline — grouping, joining, filtering, transforming
- Multi-document transactions and JSON schema validation
